# fbarretto/homebrew-tap

```sh
brew install fbarretto/tap/charcoal
```

Installs `ch` from [fbarretto/charcoal](https://github.com/fbarretto/charcoal), a fork of
[danerwilliams/charcoal](https://github.com/danerwilliams/charcoal) whose commands and flags match
Graphite's `gt`.

To publish a new version after its GitHub release exists: `./bump-charcoal.sh <version>`, commit, push.
